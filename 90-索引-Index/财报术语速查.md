# 财报术语速查表

> **用法**：这是**查**的表，不是背的表。读财报书、看真实年报（10-K / 10-Q）时遇到陌生科目，回来 Ctrl+F 搜一下即可。
> 每个术语记两条就够：**它是什么** + **它在哪张表、哪一类**。不用背定义原文，能用自己的话说清就行。
> 来源：《一本书读懂财报》肖星（微信读书划线整理）+ 后续阅读持续补充。

## 一、先记框架：企业只做三件事

| 活动 | 通俗解释 | 记在哪张表 |
|---|---|---|
| **经营活动** | 生产产品、销售产品、回收货款——每天都在做的事 | 利润表 + 现金流量表（经营活动现金流） |
| **投资活动** | 到新地区开展业务、进入新业务领域、设计生产新产品 | 现金流量表（投资活动现金流） |
| **筹资活动** | 经营和投资缺钱了，向银行借钱或找人投资 | 现金流量表（筹资活动现金流） |

> 肖星原话：「企业一辈子其实只做了三件事：经营、投资和筹资。」——三张报表就是这三件事的不同切面。

## 二、资产的两分法（资产负债表左侧）

| 大类 | 定义 | 记忆要点 |
|---|---|---|
| **流动资产** | 企业可以在**一年或超过一年的一个营业周期内**变现或运用的资产 | 一年内能变成现金 |
| **非流动资产** | 流动资产以外的资产 | 一年内变不成现金 |

> **分界的一句话**：「流动资产与非流动资产的差异就在于**是否能在一个循环之内就将自己完全变为现金**。」

| 科目 | 一句话定义 | 类别 |
|---|---|---|
| 货币资金 | 库存现金 + 银行存款 + 其他货币资金；**有专门用途的不算** | 流动 |
| 应收账款 | 因销售商品、提供劳务等经营活动**应收取**的款项 | 流动 |
| 应收票据 | 因销售商品等收到的商业票据（银行/商业承兑） | 流动 |
| 预付款项 | 按合同规定**预先支付**的款项 | 流动 |
| 其他应收款 | 上述之外的**各种应收及暂付款项**（保证金、备用金、代垫款等） | 流动 |
| 存货 | 为**出售**而持有的产成品/商品，或生产中的在产品，或耗用的材料物料 | 流动 |
| 长期股权投资 | 能对被投资单位实施**控制**（或共同控制），或具有**重大影响**的权益性投资 | 非流动 |
| 固定资产 | 有形资产：①为生产/提供劳务/出租/经营管理而持有；②使用寿命**超过一个会计年度** | 非流动 |
| 无形资产 | 拥有或控制、**没有实物形态**的可辨认非货币性资产（专利权、非专利技术、商标权、著作权、土地使用权、特许权） | 非流动 |
| 土地使用权 | 国家准许某企业在一定期间内对国有土地享有**开发、利用、经营**的权利；取得方式：行政划拨、外购、投资者投资 | 非流动 |
| 长期待摊费用 | 有效期**长于一年**的待摊费用（加「长期」二字）；**少于一年**的待摊费用直接记入相关费用 | 非流动 |
| 生物资产 | 与农业生产相关的**有生命的**动物和植物；分消耗性、生产性、公益性三类 | 按性质归类 |

### 存货的六个细项（一轮生产循环的顺序）

| 细项 | 定义要点 |
|---|---|
| 原材料 | 经加工改变形态或性质、构成产品主要实体的原料及主要材料、辅助材料、外购半成品、备品备件、包装材料、燃料等 |
| 在产品 | 正在制造**尚未完工**的产品（含各工序在加工品、已完工但未验收/未办入库手续的） |
| 半成品 | 已检验合格入库、但**尚未制造完工**成为产成品、仍需进一步加工的中间产品 |
| 产成品 | 工业企业**已完成全部生产过程**并验收入库、可按合同送交订货单位或可对外销售的产品 |
| 商品 | 商品流通企业外购或委托加工完成验收入库**用于销售**的各种商品 |
| 周转材料 | 能**多次使用**但不符合固定资产定义的材料（包装物、工具、管理用具、玻璃器皿、劳保用品、低值易耗品、钢模板、木模板、脚手架等） |

## 三、固定资产的三个衍生概念（折旧链条）

| 概念 | 定义 | 关系 |
|---|---|---|
| **预计净残值** | 寿命已满并处于终了预期状态时，处置该项资产**获得的金额扣除预计处置费用后**的净额 | 起点扣减项 |
| **应计折旧额** | 固定资产**原价 − 预计净残值** | = 原价 − 净残值 |
| **折旧** | 在固定资产使用寿命内，按确定的方法对**应计折旧额**进行系统分摊 | 把应计折旧额摊到各年 |

> 链条：**原价 →（减预计净残值）→ 应计折旧额 →（按方法分摊）→ 每年折旧**。

## 四、与美股的对照提醒

- 美股 10-K 里对应科目名不同但结构一致：Current assets / Non-current assets、Property, Plant & Equipment（PP&E，对应固定资产）、Intangible assets、Goodwill（商誉，A 股也在无形资产下）、Deferred tax assets（递延所得税资产）。
- **A 股准则（CAS）与美国 US GAAP 的差异**主要在科目命名和列报细分，分析逻辑（流动/非流动、有形/无形、是否一年内变现）完全通用。
- 读 10-K 时对照本表逐项找一遍，概念就落地了。
